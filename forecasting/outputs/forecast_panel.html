Methodology: Cognitive impairment was defined using a consistent recall score threshold (CFDCSR ≤ 4) applied to adults aged 60 and over across two NHANES cycles (2011-12 and 2013-14). Bootstrap 95% confidence intervals were computed per wave using 2,000 resamples. A linear trend line is shown for illustrative purposes; the vertical dashed line marks the observed data boundary.

Key finding: Cognitive impairment prevalence declined from 32.2% (2011-12, n=1,454) to 23.4% (2013-14, n=1,672), an 8.8 percentage-point reduction over one NHANES cycle. This pattern is consistent with published literature on cohort-level improvements in cognitive health driven by rising educational attainment and better cardiovascular risk management. Extending this analysis across additional NHANES waves would be required to confirm the trend directionally.

Limitation: A linear forecast cannot be reliably fit from two data points. The trend line above is illustrative only and should not be interpreted as a projection. Additional NHANES cycles (2015-16 cognitive data was not publicly released) would be needed to build a validated forecasting model.
